# Logo propio

Coloca aquí tu logo con el nombre `logo` y una de estas extensiones:
`.png`, `.jpg`, `.jpeg`, `.webp` o `.svg` (por ejemplo, `logo.png`).

La app lo detecta solo y lo muestra en la pantalla de acceso y en la
barra lateral, en vez del icono genérico. Si no hay ningún archivo aquí,
sigue usando el icono genérico sin dar ningún error.

Esta carpeta está excluida de git (salvo este README): tu logo se queda
en tu copia local del PC de planta y nunca se sube al repositorio de
GitHub, así que puedes usar el logo real de la empresa sin que quede
público.
